# KORObKA - Платформер

## 🎮 Описание
2D платформер с 25 уровнями, созданный на Python с использованием библиотеки Arcade.

## ✨ Особенности
- 25 уникальных уровней
- Анимированный персонаж с плавным управлением
- Звуковые эффекты прыжков
- Сохранение прогресса в базу данных
- Пиксельная графика

## 🚀 Установка

### 1. Установите Python
Скачайте и установите Python 3.7+ с [python.org](https://www.python.org/)

### 2. Скачайте проект
Скачайте архив с игрой и распакуйте в любую папку

### 3. Установите зависимости
Откройте терминал/командную строку в папке с игрой:

```bash
pip install -r requirements.txt
```

# 🎮 Запуск игры

```bash
python main.py
```
